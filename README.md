# CivilsTracker
A comprehensive UPSC Syllabus Tracker designed to help aspirants systematically cover and revise the vast Civil Services Examination syllabus. This tool breaks down the official UPSC syllabus into structured, trackable topics across Prelims, Mains, and optional subjects.

## Features

* Complete UPSC syllabus breakdown (Prelims & Mains)
* Track topic-wise progress
* Mark topics as completed / pending
* Set study goals and targets
* Revision tracking support
* Daily consistency monitoring
* Clean and distraction-free interface

---

## Why This Project?

The UPSC Civil Services Examination has a vast and dynamic syllabus, making it difficult to track coverage manually. This tracker helps you:

* Stay organized
* Avoid missing important topics
* Build consistency
* Visualize your preparation progress


## Usage

1. Open the app
2. Browse the syllabus topics
3. Mark topics as completed as you study
4. Track your progress over time
5. Revise regularly using tracked data
